각 탭은 상단 공시 목록과 하단 펀드별 권리 상세로 구성한다. 공통 AamsSplitter로 높이를 조절하며, 모바일은 두 그리드를 가용 높이의 50%씩 배치한다.

## 조회와 저장

- `GET /api/subscriptionrights/ja021g/data?tab=t1`: SJT0HK 단일 테이블 JPA 조회. 첫 진입과 탭 선택 시 자동조회하며, 미저장 변경이 있는 탭은 내용을 유지한다.
- `GET /api/subscriptionrights/ja021g/detail`: tab, trYmd, habCo, piHabCo로 SJT0H1 조회. 일반 사용자는 로그인 회사만, 관리자 사용자는 PB의 AAMS 조건과 같이 전체 회사를 조회한다.
- `POST /api/subscriptionrights/ja021g/save`: 현재 탭의 공시 변경과 상세 변경을 한 트랜잭션으로 저장한다. 작업일자, 거래코드, 회사 권한을 서버에서 검증한다.
- 업무 테이블 조회/CUD는 JPA, DUAL의 F_STOCK 휴장일 함수만 MyBatis로 호출한다.
- 공시 등록·수정은 작업일자 이후만 허용한다. 기존 자료는 원래 공시일자도 검사하여 과거 자료의 날짜 변경을 통한 우회를 막는다.
- 복사는 금지한다. 상세 추가·복사·삭제는 금지하고 대상주식수만 수정한다. 상세 버튼은 엑셀·첫행·마지막행으로 구성한다.
- 공시가 없는 탭에는 작업일자와 거래코드가 설정된 입력 행을 1개 제공한다.
- 감자·유상소각·액면분할/병합의 대상 회사와 상장 회사를 동일하게 설정한다. 이전/교환 비율은 원본의 보완 비율 계산을 적용하며 pi 필드 직접 변경 시에는 유지한다.
- 모든 날짜는 LocalDate로 전달하고 공통 날짜 포맷터·편집기·달력 버튼을 사용한다. 발행기관은 공통 코드검색을 사용한다.
