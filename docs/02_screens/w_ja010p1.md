## 3. 계층별 세부 코드 및 구성 분석

### 3.1 화면 및 클라이언트 스크립트 ([w_ja010p1.html](file:///d:/work/java_aams_html_ver/src/main/resources/templates/views/daily/w_ja010p1.html))

```javascript
function loadReport() {
    var ymd = getFilterYmd();
    var iframe = currentPane.querySelector('#report-frame');

    var rawUrl = "/api/daily/ja010p1/preview?ymd=" + encodeURIComponent(ymd) +
        "&t=" + new Date().getTime();

    // AamsReport 공통 유틸을 통한 120% 줌 부착
    iframe.src = (window.AamsReport && typeof window.AamsReport.formatPreviewUrl === 'function')
        ? window.AamsReport.formatPreviewUrl(rawUrl)
        : rawUrl + "#toolbar=1&navpanes=0&zoom=120";
}
```

### 3.2 컨트롤러 계층 (`Ja010p1Controller.java`)

```java
@GetMapping("/api/daily/ja010p1/preview")
public ResponseEntity<byte[]> previewReport(
        @RequestParam(name = "corpGr", required = false) String corpGr,
        @RequestParam("ymd") String ymd) {
    RdReportService.ExportResult exportResult = rdReportService.generateJa010p1Report(corpGr, ymd, "pdf");

    return ResponseEntity.ok()
            .contentType(MediaType.APPLICATION_PDF)
            .header(HttpHeaders.CONTENT_DISPOSITION, "inline; filename=\"ja010p1.pdf\"")
            .body(exportResult.getData());
}
```
