# W_JA021D 배당 명세표 출력

- 메뉴: `00398` / `W_JA021D`
- 화면: `/views/subscriptionrights/w_ja021d` (`/views/w_ja021d` 별칭 지원)
- 원본: `pb_recource/JA021/w_ja021d.srw`, `d_ja021d.srd`
- 리포트: `src/main/resources/rd/rd_ja021d.mrd`

출력 전용 화면으로 공통 RD 미리보기·내보내기 API를 사용한다. 별도 조회 매퍼나 저장 API는 생성하지 않는다.

공시일 시작·종료일은 회사별 작업일자로 초기화한다. 기간 달력은 일반 범위 모드이며 `preserveSameDay` 옵션으로 동일 날짜를 유지한다. 발행기관 검색은 공통 `DynamicCodeSearch`의 `balh_co`, `seq=1`을 사용하고 `%`는 전발행기관을 의미한다.

출력구분은 `Ja021dReportType`에 PB의 정적 목록과 거래코드 매핑을 정의한다.

| 출력구분 | 명칭 | gb | tr_cd |
| --- | --- | --- | --- |
| 10 | 현금예상배당 | 1 | G10 |
| 20 | 주식예상배당 | 2 | G10 |
| 30 | 현금이사회배당 | 3 | G20 |
| 40 | 주식이사회배당 | 4 | G20 |
| 50 | 현금중간배당 | 3 | G15 |
| 60 | 주식중간배당 | 4 | G15 |
| 61 | 현금중간확정배당 | 3 | G23 |
| 62 | 주식중간확정배당 | 4 | G23 |
| 70 | 현금주총배당 | 3 | G25 |
| 80 | 주식주총배당 | 4 | G25 |

RD 파라미터는 `gb`, `tr_cd`, `title`, `fr_ymd`, `to_ymd`, `balh_co`이며 날짜는 `yyyy.MM.dd` 형식이다. 회사는 공통 뷰어의 `corpGr`로 전달한다.

초기 자동 조회는 하지 않는다. 필터·회사 변경 시 기존 보고서를 유지하고, 상단 [조회]를 눌러야 갱신한다. 회사 변경 시 기준일자와 발행기관 필터만 초기화한다. 내보내기는 마지막으로 조회한 회사와 조건을 사용한다. 새로고침은 보고서를 비우고 필터를 초기화하며 재조회하지 않는다.

공통 `AamsReport.bindViewer`와 리포트 프래그먼트로 미리보기, PDF·Excel·Word·PPT·HWP 내보내기, 새 창 열기 및 모바일 모달을 연결한다.
